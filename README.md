# Spam Email Detection System

A Python-based Spam Email Detection System that classifies emails as either **Spam** or **Ham (Legitimate Email)** using machine learning algorithms.

## Feature

- Classifies emails as Spam or Ham.
- Implements Naive Bayes classification.
- Implements Decision Tree classification.
- Compares the accuracy of both algorithms.
- Provides a graphical user interface using Tkinter.

## Technologies Used

- Python
- NumPy
- Pandas
- Tkinter

## Algorithms Used

1. **Naive Bayes Classifier**
2. **Decision Tree Classifier**

## Dataset

The project uses a labeled email dataset containing two categories:

- Ham: Legitimate emails.
- Spam: Unwanted or fraudulent emails.
